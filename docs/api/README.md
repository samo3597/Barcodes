# API contracts

Այստեղ պահվում են version-controlled OpenAPI schema-ները, request/response օրինակները և 1C integration նշումները։

API contract-ների հիմնական խմբերը՝

- Source ingest API։
- Server 1 → Server 2 internal publication API։
- Public products և batch API։
- Usage և quota API։
- Feedback intake API։
- Changes cursor API։
