# Փաստաթղթեր

Այս պանակը պահում է կոդի հետ միասին version-controlled տեխնիկական փաստաթղթերը։ Սկզբնական բիզնես և տեխնիկական սահմանները նկարագրված են repository-ի արմատում գտնվող `Barcodes.md` և `DaaS_Barcodes_Phase1_Technical_Spec_AM.docx` ֆայլերում։

## Բաժիններ

- `architecture/` — համակարգի կառուցվածք, տվյալների հոսքեր և բաղադրիչների սահմաններ։
- `decisions/` — Architecture Decision Records (ADR)։
- `api/` — OpenAPI contract-ներ և integration օրինակներ։
- `runbooks/` — deployment, rollback, backup/restore և incident ընթացակարգեր։

`docs/business/`-ը նախատեսված է local վաճառքի և հետազոտության նյութերի համար և ամբողջությամբ անտեսվում է Git-ի կողմից։ Այնտեղ մի պահեք տեխնիկական փաստաթուղթ, որը պետք է հասանելի լինի repository-ի մասնակիցներին։
